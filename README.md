# 📢 학교 공지 맞춤 비서 Agent — 실행 방법

## 파일 구성
| 파일 | 역할 |
|---|---|
| `app.py` | 웹 화면 + Agent 작동 (생각 → 도구 사용 → 반복) |
| `agent_tools.py` | Agent가 쓰는 도구들 (게시판 읽기, 공지 열람, 기억, 캘린더) |
| `dashboard.html` | 한눈에 보기 화면 (타임라인·카드·캘린더) |
| `.streamlit/config.toml` | 밝은 화면 테마 설정 |
| `notices.txt` | 예시 공지 (실제 학교 공지로 바꾸세요) |
| `memory.json` | Agent의 기억 (실행하면 자동 생성) |

## 처음 한 번만: 준비
1. **Python 설치**: python.org (Windows는 "Add Python to PATH" 꼭 체크)
2. **API 키**: aistudio.google.com → Get API key → 복사 (무료)
3. 이 폴더에서 명령 프롬프트를 열고:
   ```
   pip install -r requirements.txt
   ```

## 실행
```
streamlit run app.py
```
사이드바에 API 키를 넣고 시작하세요.

## 화면 구성
| 화면 (오른쪽 위 버튼) | 내용 |
|---|---|
| 한눈에 보기 | **🤖 AI로 공지 판단하기** 한 번 → 마감 타임라인, ★ 중요 공지, D-day 카드, 태그 필터, 숨긴 공지, 캘린더 파일 받기.<br>단어 거르기: 카드에서 단어를 드래그하거나, 오른쪽 "자주 나오는 단어"를 누르면 그 단어가 들어간 공지가 빠져요.<br>"📅 캘린더 창 열기"를 누르면 캘린더만 있는 새 창이 열려요 |
| 마감 캘린더 | 캘린더만 있는 화면. 공지를 누르면 오른쪽에 상세 정보 (새 창이 막혔을 때도 이걸로) |
| Agent에게 맡기기 | 할 일을 말하면 Agent가 스스로 계획하고 도구를 골라 쓰며 일함. 일한 과정이 단계별로 보임 |
| 기억 | Agent가 기억하는 내 취향, 이미 읽은 공지 |

※ 한눈에 보기 결과는 `last_batch.json`에 저장돼서, 다시 켜도 AI를 또 부르지 않고 바로 보여요.
※ ☆ 중요 표시·관심 없음·태그·제외어 설정은 브라우저에 저장돼요.

## Agent 요소 (발표용)
- **스스로 계획**: 목표를 받으면 할 일 순서를 정하고 생각을 보여줌
- **도구 사용**: 게시판 목록 → 게시판 읽기 → 공지 열람 → 캘린더 등록을 AI가 직접 골라서 실행
- **기억**: 👍/👎와 메모를 기억해 다음 추천에 반영
- **자율 실행**: 🌅 아침 브리핑은 아직 안 읽은 새 공지만 확인 (매일 자동 실행 시나리오 시연)

## 실제 학교 게시판 연결
사이드바 "게시판" 칸에 한 줄에 하나씩 입력:
```
학교 공지 | https://게시판주소
학과 공지 | https://게시판주소
```
비워두면 `notices.txt` 예시 공지를 사용합니다.
※ 사이트에 따라 공지가 잘 안 읽힐 수 있어요. 그럴 땐 게시판 주소를 Claude에게 보내서 맞춰 달라고 하세요.

## 시연 팁
- 시연 전에 🧠 기억 탭에서 **읽은 공지 초기화** → 아침 브리핑에서 새 공지가 잡혀요
- 한 번 실행하면 결과가 저장돼서, 발표 중 인터넷이 끊겨도 **📂 지난 결과 불러오기**로 보여줄 수 있어요
- 👎 누르기 / "대외활동은 관심 없어" 메모 → 다시 실행하면 결과가 바뀌는 장면이 Agent의 기억을 보여줘요

## 오류가 날 때
- `AI 호출 실패` → API 키 확인. 계속 안 되면 `app.py` 위쪽 `MODELS`에 AI Studio에서 보이는 모델 이름 추가
- 그 밖의 오류 → 화면을 캡처해서 Claude에게 보내기
